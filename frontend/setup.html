    Lokales Administratorkonto anlegen

    Mit diesem Konto melden Sie sich nach der Einrichtung an. Active Directory und Entra ID richten Sie später im Bereich Administration ein. Mit * gekennzeichnete Felder sind Pflichtfelder.

    1–64 Zeichen: Buchstaben, Ziffern sowie . _ @ -

    Mindestens 12 Zeichen.

    Webzugriff festlegen

    Diese Einstellungen gelten nach dem Neustart des Servers.

    127.0.0.1 für lokalen Zugriff; 0.0.0.0 für alle IPv4-Netzwerkschnittstellen des Servers.

    Verbindung

    Die Adresse Ihres Reverse Proxys, optional mit Port. Verwenden Sie eine eigene Domain oder Subdomain ohne Pfadpräfix wie /switchsteward.

    Beide Dateien müssen bereits auf dem Server vorhanden sein. Geben Sie Dateipfade an, keine Zertifikats- oder Schlüsselinhalte.

    Für die Anmeldung über ein Netzwerk richten Sie HTTPS oder einen HTTPS-Reverse-Proxy ein.

    Installation abschließen

    Die benötigten Anwendungsdateien werden beim Einrichten automatisch angelegt. Vorhandene Daten bleiben erhalten.

    Wählen Sie für die Ersteinrichtung eine neue Datenbankdatei. Sie speichert unter anderem Switches und Einstellungen. Ein fehlendes übergeordnetes Verzeichnis wird angelegt.

    Globale Gerätezugangsdaten hinterlegen (optional)

    Standardzugang für Switches und WLCs. Geben Sie Benutzername und Passwort zusammen an. Eigene Zugangsdaten pro Gerät können Sie später in der Anwendung hinterlegen. Das Enable-Secret gilt nur für Switches.

    Weitere Dateipfade (optional)

    Leer lassen für die Systemvorgaben. Fehlende Dateien an den angegebenen Pfaden werden leer angelegt. Tragen Sie dort vor der ersten Switch-Verbindung die vertrauenswürdigen Host-Schlüssel ein. Bestehende Einträge bleiben erhalten.

    Alle Dateipfade beziehen sich auf den Server, auf dem SwitchSteward läuft. Relative Pfade werden vom Konfigurationsverzeichnis aus aufgelöst.
